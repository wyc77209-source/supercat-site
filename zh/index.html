面向留学生的 AI 省钱助手

招财猫（Super Cat）是面向大学生和留学生的免费助手。输入你的开销（外卖、流媒体、打车、订阅等），即可获得按优先级排序、并附公开来源的建议。

  • ✓ 免费且注重隐私 — 花销数据只留在你的手机上
  • ✓ 无需账号 — 打开就能开始
  • ✓ 根据所在地和画像给出智能建议
  • ✓ 在本机记录已实现的节省与回访提醒

怎么用

  1. 告诉招财猫你把钱花在哪（外卖、订阅、交通等）
  2. 查看按优先级排序、并附来源的行动清单
  3. 打开每条建议的来源，挑选适合你的去尝试
  4. 在本机标记已完成的建议，记录实际省下来的钱

功能

  • 账单扫描：在这台手机上拍账单。招财猫标出有出处的加项，并给出一步步通话稿 — 不会上传
  • 通勤工具：对比交通月票，按你的行程找更省方案
  • 我的钱包：收藏建议、管理订阅与提醒
  • 纽约二手指南：可靠二手店与学生优惠
  • 7 天回访：可选提醒，帮你坚持执行省钱建议

常见省钱类别

  • • 外卖（DoorDash、Uber Eats）— 自己做饭、备餐、学生餐饮计划
  • • 流媒体（Spotify、Netflix）— 学生价、家庭组、捆绑优惠
  • • 交通（Uber、Lyft、停车）— 月票、共享单车、步行路线
  • • 手机与网络 — 学生套餐、家庭计划、更便宜的运营商
  • • 购物 — 二手、学生折扣、转售平台

校园相关提示

招财猫会把 NYU、UCI 当作校园提示主题（餐饮、交通、健身等），不是这两所学校的官方资源。

隐私与数据

你的花销信息不会离开设备。招财猫把所有内容存在本机。我们仅统计匿名使用数据（页面打开、按钮点击）以改进产品 — 从不记录你输入的内容或具体金额。
